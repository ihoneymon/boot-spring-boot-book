부트 스프링 부트 `Boot Spring Boot`
====================

* 작성자: 허니몬 <ihoneymon@gmail.com>

> 스프링 부트 `Spring Boot` 를 기반으로 하는 개발가이드

## 문서생성을 위한 사전요구사항
* [rbenv](https://github.com/rbenv/rbenv) 로 Ruby 3.3.7 설치
* [bundler](http://bundler.io/) 설치

```
$ rbenv install 3.3.7
$ gem install bundler
```

## 문서빌드
```
$ bundle install
$ ./build.sh
```
